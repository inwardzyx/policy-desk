## 二、岗位筛选：6 条硬规则（30 秒判断一个 JD）

```text
1  只投「今日活跃 / 刚刚活跃」的 Boss —— 不活跃的发了等于扔进黑洞
2  学历写「本科及以上」且没写「优秀者可放宽」→ 跳过（你是五年制专科段在读）
3  届别写「2027 届 / 2028 届」→ 先打招呼问一句「接受 2029/2030 届在校生吗」再投
4  职责里出现「独立负责项目 / 从 0 到 1 / 对结果负责」但招实习 → 跳过（要熟手）
5  优先投写「接受在校生 / 有导师带 / 工作偏基础协助」的
6  优先投「3 天内发布」的 —— 挂了两个月的岗位基本不招人
```

**岗位类型优先级**（你 200 份的教训：AI 应用岗在中小厂很少，且要独立交付）：

```text
① 测试开发实习        ← 学历最松，你的评测纪律直接对得上
② AI 数据 / 标注 / 评测 ← 新，缺人，接受在校生
③ 后端（Java）实习     ← 岗位多，竞争大，但你有真项目
④ 技术支持 / 实施      ← 门槛低，先进公司
⑤ AI 应用开发         ← 最后，中小厂这个岗少且要求高
```

## 三、7 天执行节奏

```text
每天 15–20 条，工作日 9:30–11:00 或 14:00–16:30 发
第 1 天 只投测试/AI 数据两类（话术 B / C）
第 2 天 开始回捞：24h 没回的补一条（只补一次，带新信息）
第 3–5 天 加后端类（话术 A）
第 6 天 不投，复盘：算三个率（见下）
第 7 天 按复盘结论决定加量还是换池
```

**跟进话术（24h 后，只发一次）**：

```text
您好，看到您已经看过了。我补一句：可立即到岗、每周 4–5 天、能连续做 6 个月，薪资按贵司标准。
如果这个岗位还缺人，您回我一个字「行」就行，我马上把简历发过来；不合适也没关系，不回复我也理解。
```

## 四、三个率，和它们对应的动作

```text
已读率 = 已读 / 投递      正常 40–70%
回复率 = 回复 / 已读      正常 15–30%
面试率 = 面试 / 回复      正常 20–40%
```

判断分支（这是这份清单的核心）：

| 现象 | 说明 | 改什么 |
|---|---|---|
| 已读率 < 30% | 招呼语/在线简历标题没吸引点开 | 换前 15 字；改在线简历第一屏 |
| 已读率正常，**回复率 < 5%** | 点开后被筛掉 = 简历/匹配度/届别 | 换岗位池（往 ①② 走），别改话术 |
| 回复率正常，面试率 < 20% | 沟通环节问题 | 看聊天记录，是不是答反问句答得太长 |
| 三个率都正常但量太小 | 投得少 | 加量 |

## 五、今天先发这 5 条（照抄，只改公司/岗位名）

```text
1  [测试开发实习]   话术 B
2  [测试开发实习]   话术 B
3  [AI 数据/标注]   话术 C
4  [AI 数据/评测]   话术 C
5  [Java 后端实习]  话术 A
```

**为什么先发这 5 条**：它们是"学历最松 + 你最能对上"的组合，用来**验证话术是否有效**，而不是用来碰运气。5 条的回音能告诉你方向对不对。

## 六、三条不要做

```text
✗ 不要用「一键投递」—— 那是黑洞，改成主动打招呼
✗ 不要在晚上/周末投 —— 回复率明显低
✗ 第一次聊天不要问薪资、几轮面试、能不能转正 —— 那是拿到面试之后的事
```

## 七、什么时候该换策略

```text
连投 30 条、已读率<30%           → 问题在招呼语（回去改前 15 字）
连投 30 条、已读正常但回复<5%     → 问题在岗位池（换 ①② 类）
连投 30 条、回复 5 条以上但没约面  → 问题在沟通（复盘聊天记录）
```
