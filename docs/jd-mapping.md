## 二、简历改了什么（相对上一版）

1. **技能首行从"Agent 循环"扩成"Agent 工程"**，把 JD 的四个词一次覆盖：
   函数/工具调用、MCP、上下文工程、SSE；并补一句 LangGraph 对照实验（不吹"熟悉框架"）。
2. **后端行补"异常与降级"**——对应 JD 里"日志/异常处理/权限边界"。
3. **项目正文补两处**：LangGraph 重写同一循环（量过换了什么）；上下文八层 + 预算 + trace。
4. **评测行加"判据版本"**：这是别人没有的、能一句话讲清的差异化。
5. 版式：边距 10.5mm / 9.6pt，仍是一页（PDF 回读 1 页）。

## 三、还缺什么（投递前要么补，要么准备被问时怎么说）

| 缺口 | 严重度 | 怎么补（成本） |
|---|---|---|
| **Memory（长期记忆）/ Skill 机制** | 中 | 现在的"多轮会话"只是短期上下文；补一个"会话记忆摘要"半天可做 |
| **多智能体** | 低（实习少问） | 不补；被问就说"先做单 agent，因为评测口径更难定" |

## 四、对照"优秀简历写法"的三条自查

参考：《[简历中大厂相关实习经历撰写指南](https://blog.csdn.net/chenby186119/article/details/150006180)》（具体量化 / 职责-行动-结果 / 关键词匹配 / 动词开头 / 每条 ≤2 行）。

| 原则 | 我这版 |
|---|---|
| 每条 ≤2 行 | ✅ 目测全部 ≤2 行（工作 4 条、难点 2 条、结果 2 条） |
| 动词开头、避免"负责/参与" | ✅ 全是"手写/改/量出/抓出/钉住" |
| 有分母、有产物 | ✅ 42/44、40/61、63+16+473、16 条单测 —— 每个数都能指回报告 |
| 关键词匹配 | ✅ 见上表；⚠️ 有一处**刻意不写**："熟悉 LangChain"（只写对照实验） |

## 五、投递时的一句话自我介绍（按 JD 调）

> "我做了一个制度问答 Agent：它自己决定调几次工具，前端能看到每一步；
> 我还给它配了一套评测门禁——105 题盲出、先量噪声地板再谈差异，
> 就是靠它抓出'模型改写问法绕过拒答'这个 bug 的。"

三种岗位微调：
- **Agent 岗**：先说"工具调用 + MCP + 过程可见"，评测放第二句。
- **AI 应用开发**：先说"RAG + 全栈链路（Vue→Java→Python）"，再提评测。
- **AI 测试 / 质量**：先说"评测门禁 + 拒答语义"，工具链放第二句。
