项目详情
  • 工具调用链路：手写循环 for rnd in range(rounds_limit)（默认 6 轮），每轮 「模型选工具 → 执行 → 结果回填」；工具通过 MCP 运行在独立进程（客户端与服务端都自己实现， 含协议测试）。
  • 参数校验与异常返回：工具入口校验必填与长度，超时 5 秒返回结构化错误、不抛异常； 失败按「超时 / 参数 / 权限」三类归类并写进 trace，便于定位。
  • 权限控制：角色 → ACL 单向投影，检索与工具都按角色过滤，越权请求直接拒； 审计事件带 tenant，支持按租户导出。
  • 日志排查与回归用例：按执行日志定位工具失败在哪一步；16 条单测钉住「算不算成功」 （缺 result 事件即判状态未知，不显示成功）。
  • 上下文与多轮：上下文八层 + token 预算 + trace；多轮会话保留最近 3 轮原文、更早截断， 响应带 session_used 如实报是否用上历史。
  • Java 接口与交付：Spring Boot 3 写 REST 接口与 SSE 流式透传（Java 只搬字节不解析）； Docker Compose 五容器部署，两仓 CI 覆盖后端、前端、容器与评测。
