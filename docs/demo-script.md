# 3 分钟演示脚本（录像用）

> 目标不是"炫技"，是让人在 3 分钟内记住一句话：
> **它不只是个问答，是能证明自己没变坏的那种问答。**
>
> 录像对象：面试官 / 简历上的链接。**录屏比链接活得久**——链接会随机器重启失效。

---

## 一、录像前 10 分钟（逐项勾）

```text
☐ cd D:\policy-desk\deploy && docker compose up -d
☐ docker compose ps              # 五个服务都 healthy
☐ \policy-desk\scripts\demo-seed.ps1   # 准备 demo 分区（两篇：public + hr）
☐ 浏览器开无痕窗口，只留一个标签页：http://localhost:8088
☐ 窗口 1440×900（再大在视频里字太小），缩放 100%
☐ 关通知（Win → 专注助手 → 仅闹钟）；关微信/QQ
☐ 先自己走一遍三条问题，确认都正常（尤其是 emp 拒答那条）
☐ DeepSeek 余额 > 1 元（一轮演示约 15 次调用）
```

★ **录像走 `localhost:8088`，不要用公网 tunnel 地址**：tunnel 会抖，而且 URL 栏里的随机域名对观众是噪音。
公网地址只在"发给对方自己点"时用。

## 二、时间轴（逐字旁白，可直接照读）

| 时间 | 你在做什么 | 旁白 |
|---|---|---|
| **0:00–0:15** | 停在登录页 | "这是我做的一个企业制度问答服务。它要解决的不是'能不能答'，是**答得对不对、事后能不能查**。" |
| **0:15–0:35** | 用 `hr_demo / policy123` 登录 | "先登录。系统里有两个角色：人事和普通员工，能看到的条款不一样——一会儿我用**同一个问题问两遍**。" |
| **0:35–1:10** | 问「加班费怎么算？」→ 答案出来后，鼠标停在 `[1]` 和下面的引用块上 | "我问一句加班费。…… 看这里：答案里带编号，下面就是那一条原文。**这是第一件事：每条答案都能核验出处。**" |
| **1:10–1:30** | 问「食堂几点开饭？」（库里没有） | "再问一个库里没有的。它不会编，直接说不知道。**这是第二件事：答不出就明确拒答。**" |
| **1:30–2:05** | 退出 → `emp_demo / policy123` 登录 → 问**同一句**「加班费怎么算？」 | "现在换成普通员工，问一模一样的问题。…… **拒答了。** 因为那条薪酬条款的权限是'仅人事'。<br>注意这不是服务坏了——员工问年假是能答的（可顺手点一下）。<br>**差别只来自令牌里的角色**，请求体、URL、参数一个字都没变。" |
| **2:05–2:35** | 进「文档」页 → 上传一个小 `.md`，ACL 选 `hr` → 看到"该分区共 N 块" | "管理员这边可以传文档、选权限，传完立刻能问——索引是热更新的，不用重启。" |
| **2:35–3:00** | 回到问答页，或者停在文档页 | "整套东西一条 `docker compose` 起来：前端、业务、算法、数据库、缓存五个容器。<br>仓库里有 63 条后端测试、4 条前端测试，还有一套评测门禁——**它拦过我自己的改动**。<br>一句话：它不只是个问答，是**能证明自己没变坏**的那种问答。" |

**旁白总字数约 430 字**，正常语速 3 分钟内读完，留了停顿。

## 三、三句演示问题（已实测，别再换）

| 谁问 | 问题 | 应该看到 |
|---|---|---|
| `hr_demo` | 加班费怎么算？ | 命中「加班与补贴」，答 1.5 / 2 / 3 倍，带 `[1]` |
| `emp_demo` | 加班费怎么算？ | **拒答**：知识库里没有能回答这个问题的资料 |
| `emp_demo` | 年假有几天？ | **能答**（证明拒答是权限造成的，不是服务坏了） |

最后一条一定要演。**只演"拒答"会被误读成"这系统不好使"**；补一条"员工能答年假"，对比才成立。

## 四、不要说的话

| ❌ 别说 | ✅ 换成 |
|---|---|
| "这是一个 RAG 项目" | "这是一个可核验的制度问答服务" |
| "我用了 LangChain / 向量库" | "混合检索 + 精排 + 出处校验"（技术细节等他问） |
| "准确率 90%"（没有分母） | "20 题验收：应答 17/17、拒答 3/3"（有分母、有产物） |
| "支持多租户、SSO、审计" | 只讲屏幕上看得见的，其余留到被问 |
| "数据不出内网" | "文档和检索在本机，生成调 DeepSeek——可以换内网模型" |

## 五、翻车预案

| 现象 | 处理 |
|---|---|
| 问答卡住 > 10 秒 | 别等。停 2 秒说"这次有点慢"，**重新点一次**；两次都卡就跳过，最后补一句"健康检查里能看到上游状态" |
| emp 那条没拒答（模型硬答） | 立刻重录这一段——**这条是本片的论点**，不能含糊 |
| 上传报 413 | nginx `client_max_body_size` 与 Java `multipart` 上限没对齐；换小文件先录完 |
| 页面白屏 | 99% 是 compose 里 web 没起来：`docker compose ps` 当着镜头敲一下，反而是加分项 |
| 网络断了 | 录像走 localhost，不受 tunnel 影响 |

## 六、录制与导出

```text
分辨率：1920×1080 录制，导出 1080p
时长：控制在 3 分 10 秒以内
命名：policy-desk-demo-<日期>.mp4
存放：D:\policy-desk\docs\（体积大就别进 git，放网盘/简历附件）
```

★ 录两遍，挑一遍。**第一遍基本都会卡壳**，别指望一条过。

## 七、5 分钟加长版（可选，面试后发给对方）

在 3 分钟版之后追加：

```text
+ 0:20  终端：docker compose ps         → 五个 healthy（"可交付"的直接证据）
+ 0:30  终端：docker compose logs -f api | head   → 出事能从日志定位
+ 0:40  MySQL：SELECT decision, COUNT(*) FROM audit GROUP BY decision
        → 回答/拒答/配额拒绝 分开计数（"被拒也留痕"）
+ 0:50  scripts\eval_loop.py 跑一次      → 门禁输出（"我拒绝过看起来更好的改动"）
```
