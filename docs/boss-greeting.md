# BOSS 直聘打招呼话术（周语昕专用）

> 调研依据：[搜狐·求职时，打招呼的前 15 个字最重要](https://www.sohu.com/a/1062827360_121427536)（2026-08）
> + BOSS 直聘的产品机制（消息列表只显示 1–2 行、在线简历优先展示、Boss 与 HR 的差别）

---

## 一、先理解这套机制

```text
消息列表只显示前 15–20 个字   → 这 15 个字决定对方点不点开
一条招呼的决策时间 < 2 秒      → 没时间铺垫、没时间客套
一个热门岗位 2000+ 份简历      → 你的对手不是"更好的简历"，是"更先被点开"
```

**结论：前 15 个字不是自我介绍，是价值预告。**

## 二、三个必死的写法（对照你自己有没有犯）

| 你会想写 | 为什么死 |
|---|---|
| "您好，我对贵司的岗位很感兴趣，可以聊聊吗？" | 零信息量。99 个人都这么写 |
| "我是韩山师范学院的学生，想找一份实习" | 先说学校 = 先说短板 |
| "希望能有一个学习的机会" | 企业不是学校。他要的是"你能干什么" |

## 三、你的前 15 个字该怎么设计

你没有"3 年经验"可写，但你有三样别人很少有：

```text
① 独立做过完整系统（前端+后端+算法+部署）
② 有可点的 GitHub，CI 全绿
③ 现在就能来，能连续做 6 个月
```

**前 15 字从那三样里挑一样，不要写学校、不要写"热爱学习"。**

## 四、三个岗位各一套（可直接复制）

### A. 后端 / 全栈实习

```text
您好，我独立做过一个完整系统：Spring Boot 3 + MySQL + Redis 写后端、Vue 3 写前端、
Python 做检索，Docker Compose 一条命令部署，63 条测试 + CI 全绿（GitHub 可点）。
在校，可立即到岗、每周 4–5 天、能连续做 6 个月。方便看下简历吗？
```

**第一句的设计**：`独立做过一个完整系统` —— 7 个字，直接给"能干活"的信号。

### B. 测试开发实习

```text
您好，我做过一整条测试链路：63 条后端单测 + 前端单测 + CI 三 job，
还用变异测试验证"判据在坏环境下会不会红"（24 个变异脚本）。
在校，可立即到岗、每周 4–5 天、连续 6 个月。想投贵司测试开发实习，方便聊两句吗？
```

**第一句的设计**：`我做过一整条测试链路` —— 和 JD 的"测试"直接对上。

### C. AI 数据 / 标注 / 助理

```text
您好，我做过文档入库与质检：286 块材料逐条过规则，放行 263、拦下 23，每条拦截都有理由可查；
也做过 105 题评测集的人工核对。这类需要细心和条理的活我做得来。
在校，可立即到岗、每周 4–5 天。方便看下简历吗？
```

**第一句的设计**：`286 块…放行 263、拦下 23` —— 数字证明"我真的逐条看过"。

## 五、发送纪律（比话术更重要）

```text
☐ 时间：工作日 9:30–11:00 或 14:00–16:30；周末和晚上回复率明显低
☐ 对象：只投「今日活跃 / 刚刚活跃」的 Boss（不活跃的发了等于扔进黑洞）
☐ 长度：一条消息讲完，100–130 字；不要拆成三段发
☐ 结尾：一句具体的问题（"方便看下简历吗"），不要"在吗"
☐ 附件：先确认「在线简历」填完整——BOSS 默认展示的是在线简历，不是附件
☐ 频率：同一个岗位只发一次；已读不回 24h 后可补一条带新信息的，不要问"看了吗"
☐ 主动确认：收到回复先问一句「贵司接受在校生 / 2027 届实习吗」，省得聊半天才发现不招
```

## 六、被回复之后的第一句

```text
谢谢！我这边可以随时面试（线上/电话都行）。
如果方便，我可以先发一份 PDF 简历 + 两个仓库链接（CI 都是绿的，能直接看代码）。
```

**不要**在第一次回复里就问薪资、问几轮面试、问转正——那是拿到面试之后的事。

## 七、自查清单（发之前逐条过）

```text
☐ 前 15 个字里有"能干什么"或一个数字，没有"您好我很感兴趣"
☐ 全文没有"学习机会""希望成长""锻炼自己"
☐ 到岗时间写死在消息里（可立即到岗 / 每周 4–5 天 / 连续 6 个月）
☐ 一条消息，不分段
☐ 对象是今天活跃过的 Boss
☐ 在线简历已填完整、有一页 PDF 和两个仓库链接
```

## 八、一周的节奏（别一天投完）

```text
每天 15–20 条，投 5 天 = 75–100 条
第 2 天开始回捞：对已读不回的补一条新信息（新做的东西/新证据），只补一次
周末不投，用来复盘：把回复率高的岗位类型记下来，下周加码
```
