# BOSS 直聘招呼语（周语昕 · 2026-11 版）

> 上一版（按"测试开发/数据标注"投）保留在 git 历史里；这一版按 **PolicyDesk + 评测门禁** 重写。
> 调研依据：BOSS 的消息列表只显示前 15–20 个字、在线简历优先于附件、热门岗位 2000+ 份简历。

## 一、先理解机制（没变）

```text
消息列表只显示前 15–20 个字   → 这 15 个字决定对方点不点开
一条招呼的决策时间 < 2 秒      → 没时间铺垫、没时间客套
你的对手不是"更好的简历"，是"更先被点开"
```

**结论：前 15 个字不是自我介绍，是价值预告。**

## 二、三个必死的写法

| 你会想写 | 为什么死 |
|---|---|
| "您好，我对贵司的岗位很感兴趣，可以聊聊吗？" | 零信息量，99 个人都这么写 |
| "我是韩山师范学院的学生，想找一份实习" | 先说学校 = 先说短板 |
| "希望能有一个学习的机会" | 企业不是学校，他要的是"你能干什么" |

## 三、三套招呼语（按岗位挑，直接复制）

### ① AI Agent / LLM 应用岗

```text
您好，我做了 PolicyDesk：一个制度文档问答 Agent（Python/FastAPI + Spring Boot + Vue），
模型自己决定多步检索、答案带条款出处；用 105 题盲出集做评测，gold 42/44、拒答 40/61。
可立即到岗，每周 4-5 天。
```

### ② 评测 / 数据质量 / 算法质量岗（命中率最高）

```text
您好，我做了 PolicyDesk 的评测门禁：9 个场景套件、156 条场景用例、105 题盲出集，
用 exact McNemar 加噪声地板判断改动是否显著，已接进 CI，并拦下过一次真实退化。
可立即到岗，每周 4-5 天。
```

### ③ 后端 / 全栈岗

```text
您好，我独立做了 PolicyDesk（Vue + Spring Boot + Python/FastAPI 三层），Agent 用 MCP 调工具、
SSE 流式输出；后端 63 条、前端 16 条、算法层 541 条测试，两个仓库 CI 均绿。
可立即到岗，每周 4-5 天，能连续 6 个月。
```

**共同结构**：`项目名 + 是什么` → `两个数字` → `什么时候能来`。

## 四、已读不回时的第二条（隔天发，只补一次）

```text
您好，补一条：仓库在 github.com/inwardzyx，policy-desk 里有一张 Agent 时间线截图，
能直接看到模型每一步查了什么、命中几条，评测报告也在里面。
```

## 五、三个高频追问

**你是哪届的？**

```text
我是 2025 级五年制专本衔接，2030 年毕业。现在课程不冲突，可以立即开始实习，
每周 4-5 天、连续 6 个月；如果岗位需要长期培养，我能一直做下去。
```

**有实习经历吗？**

```text
还没有正式实习。这个项目从检索、Agent 循环到评测都是我自己做的：105 道题是我出的，
先量了噪声地板才敢比较改动，所以报告里的数字都能复现。
```

**熟悉向量数据库吗？**

```text
专用的向量库我还没上过。语料只有 68 块，用的内存向量检索，加载加建库 3.6 秒够用；
我在依赖文件里写了注释：语料上千条再上 faiss / HNSW。原理我清楚，换库是接口适配的问题。
```

## 六、发送纪律（比话术更重要）

```text
☐ 时间：工作日 9:30–11:00 或 14:00–16:30
☐ 对象：只投「今日活跃 / 刚刚活跃」
☐ 长度：一条讲完，100–130 字，不拆成三段
☐ 结尾：一句具体的问题（"方便看下简历吗"），不要"在吗"
☐ 附件：先确认「在线简历」填完整——BOSS 默认展示在线简历，不是附件
☐ 频率：同一岗位只发一次；已读不回 24h 后补一条带新信息的
☐ 确认：收到回复先问「贵司接受 2030 届长期实习吗」，省得聊半天才发现不招
```

## 七、发之前逐条自查

```text
☐ 前 15 个字里有"能干什么"或一个数字
☐ 全文没有"学习机会""希望成长""锻炼自己"
☐ 到岗时间写死在消息里
☐ 一条消息，不分段
☐ 对象今天活跃过
☐ 在线简历已填完整、有一页 PDF 和两个仓库链接
```

## 八、一周节奏

```text
每天 15–20 条，投 5 天 = 75–100 条
第 2 天开始回捞：对已读不回的补一条新证据，只补一次
周末不投，复盘：回复率高的岗位类型记下来，下周加码
```
